# Supplementary Methods: Reproducibility Details

## Descriptive nocturnality summaries

For descriptive summaries, land-use means and 95% bootstrap CIs were estimated
by resampling independent detections with replacement and recalculating
group-size-weighted means.

Independent detection events were the bootstrap sampling units and were sampled
uniformly within each species and land-use category. The number of individuals
recorded per detection was used once, as the analysis weight when recalculating
each bootstrap mean; it was not used as a resampling probability. Confidence
intervals were the 2.5th and 97.5th percentiles of 4,999 bootstrap replicates.
For contrasts relative to minefields, each land-use sample and the minefield
reference were resampled independently within the same replicate, after which
the weighted minefield mean was subtracted from the weighted land-use mean.
